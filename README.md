# OpenTube

**OpenTube** - это неофициальный клиент YouTube, созданный одним разработчиком - **Lipton**.

Проект разработан для удобного просмотра YouTube без рекламы и лишних ограничений. OpenTube позволяет пользоваться YouTube через отдельное приложение и может быть полезен в ситуациях, когда доступ к сервису ограничен.

## Возможности

- 🎬 Просмотр видео YouTube в отдельном приложении.
- 🚫 Полное отсутствие рекламы.
- ⚡ Современный и удобный интерфейс.
- 🌍 Возможность использования при ограничениях доступа к YouTube (при наличии доступного подключения).
- 🔄 Регулярные обновления и развитие проекта.

## Зачем был создан OpenTube?

Основная цель проекта - предоставить пользователям удобный способ просмотра YouTube без рекламы и без необходимости открывать браузер.
